# ADR 0002: Make Red Hat the primary platform story

Status: accepted

## Context

The intake and onboarding commands contain Intel Quickstart Factory defaults. The requested learning experience is intended to showcase Praxis on an aligned Red Hat platform.

## Decision

The architecture and learning outcomes lead with Red Hat OpenShift and related Red Hat capabilities. Intel details are conditional co-branding when required by the publication channel or target environment. Praxis is identified accurately as an upstream project rather than a Red Hat-supported product.

## Consequences

Generated intake/onboard output must be reviewed for inherited Intel-first wording. Hardware claims are included only with evidence and required branding approval.
